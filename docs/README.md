# Documentation

These guides preserve reusable AI-collaboration architecture, configuration, and validation knowledge that does not belong inside an invocable skill or a maintenance tool.

| Guide | Purpose |
| --- | --- |
| [Persistent & Enforced Context](persistent-enforced-context/) | Separate behavioral instructions, user context, project rules, reference sources, and historical retrieval; deploy the architecture across ChatGPT, Claude Code, Codex, and their applicable desktop surfaces; and regression-test changes. |
| [Runtime Portability](runtime-portability.md) | Author one portable workflow for Claude Code and Codex, map the applicable Claude Desktop and ChatGPT desktop surfaces, isolate vendor adapters, and validate each claimed target independently. |

Documentation can explain a runtime or provide material to configure it, but cloning this repository does not install the documented configuration into any AI platform.
